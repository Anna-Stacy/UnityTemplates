# UnityTemplates/ToolKit

This template is meant for Unity / C# scripts that can be reused without needing to change the core logic of the scripts!

The focus of this project is to create different reusable puzzle systems for puzzle / escape room type games. This includes things such as sequence puzzles, tagged objects, slot based puzzles, destroy / repair states and puzzle progression.

For now the project is being developed as a desktop 3D application in Unity 6, but the scripts and puzzle logic are being kept separate from the player input so that XR can potentially be added later on.

**This project is currently a WIP and will be expanded and changed throughout development!**
